## 6. Narrative sequence

**Layout grammar:** system map / network / operating-model transition — not a decorative orbit graphic (`SPEC.md` §7.5).

Story, per `SPEC.md` §7.5 (six points, all framed as direction, none as current state):

1. **Existing products end at organisational boundaries.** Inspection tools, contractor systems and spreadsheets each stop at the edge of the organisation that owns them.
2. **The building remains the persistent subject.** Every organisation that touches a building changes; the building's record doesn't have to.
3. **Widian gives every party a controlled way to contribute.** Surveyors, contractors, and clients each add to the same record within their own permissions — not through a separate submission to a separate system. *[Claim: Multi-organisation roles and permissions — Verified — this specific mechanism is real today, even though the "market" framing around it is future-facing.]*
4. **Every verified event increases the usefulness of the record.** A record with more genuine history is more useful than one that starts from nothing each time.
5. **Repeated participation can create network effects.** As more organisations work through the same buildings' records, the record becomes the natural place to coordinate — this is a hypothesis Widian is building toward, not a measured effect yet.
6. **Future commercial services may form around trusted workflow infrastructure.** This is explicitly a possibility, not a roadmap commitment or existing offering.

**Closing line (approved language, use verbatim):**

> The network grows around the record. The record never loses its building.
