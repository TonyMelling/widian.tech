# Widian Website — Agent Roles and Handoffs

## Recommended team

These are specialist perspectives, not necessarily separate paid people. One capable person or agent may hold multiple roles, but should declare which role they are performing.

## 1. Creative Director

**Owns:** Overall creative quality and coherence.

**Responsibilities:**

- protect “One Record, Unbroken”;
- make the site recognisably Widian;
- ensure every page has distinct art direction;
- reject generic SaaS patterns;
- resolve visual conflicts between brand, UX and motion.

**Outputs:**

- creative direction;
- page art-direction briefs;
- visual review notes;
- final creative approval.

## 2. Brand Strategist

**Owns:** Category, positioning and audience hierarchy.

**Responsibilities:**

- define the Building Record category;
- articulate the market-infrastructure opportunity;
- maintain message hierarchy;
- prevent marketplace claims from exceeding reality;
- align role stories to one shared proposition.

**Outputs:**

- message framework;
- audience matrix;
- category narrative;
- positioning approval.

## 3. Senior Conversion Copywriter

**Owns:** Complete persuasive website copy.

**Required profile:** B2B SaaS/platform experience plus regulated, property, safety or complex operational subject matter.

**Responsibilities:**

- write full page copy;
- develop narrative depth beneath approved headlines;
- address objections;
- create CTA and form copy;
- prevent repetition between pages;
- write metadata and microcopy;
- maintain British English and Widian voice.

**Outputs:**

- page briefs;
- complete copy deck;
- CTA matrix;
- form and error copy;
- SEO metadata;
- final copy approval.

## 4. Product Truth Reviewer

**Owns:** Accuracy of product-functionality claims.

**Responsibilities:**

- compare copy with deployed staging behaviour;
- check repository current-state documentation;
- distinguish current, partial, proposed and future functionality;
- ensure status terminology matches actual workflow.

**Outputs:**

- updated claims register;
- approved qualifications;
- blocked-claim list;
- dated approval.

## 5. UX Architect

**Owns:** Information architecture and visitor journeys.

**Responsibilities:**

- design sitemap and navigation;
- map primary journeys;
- design page-level information sequencing;
- avoid thin or duplicative pages;
- define progressive disclosure;
- design form and error journeys.

**Outputs:**

- sitemap;
- journey maps;
- mobile-first wireframes;
- interaction requirements.

## 6. Senior Web/Visual Designer

**Owns:** Responsive page design and design system.

**Responsibilities:**

- implement Widian’s visual language;
- differentiate page layouts;
- define responsive typography and grids;
- design product demonstrations;
- create high-fidelity mobile and desktop compositions;
- document visual tokens and states.

**Outputs:**

- design system;
- high-fidelity designs;
- responsive specifications;
- annotated component states.

## 7. Graphic Designer / Art Director

**Owns:** Brand assets, diagrams and campaign-quality imagery.

**Responsibilities:**

- prepare approved logo exports;
- create architectural Building Record artwork;
- create diagrams and evidence-led illustrations;
- produce social-sharing cards;
- ensure visual assets do not imply fake functionality.

**Outputs:**

- SVG lock-ups;
- illustration system;
- diagram assets;
- social and campaign assets;
- asset licence record.

## 8. Motion Designer

**Owns:** Narrative motion and choreography.

**Responsibilities:**

- storyboard fragmentation-to-record transformation;
- define the continuous thread behaviour;
- create page-specific motion;
- avoid decorative loops;
- produce reduced-motion equivalents;
- specify timings and easing.

**Outputs:**

- motion storyboard;
- animation specification;
- prototypes;
- reduced-motion mapping.

## 9. Senior Frontend Engineer

**Owns:** Production implementation.

**Responsibilities:**

- establish Next.js architecture;
- implement semantic, accessible components;
- maintain performance;
- implement motion without excessive JavaScript;
- create tests;
- preserve deployment boundaries.

**Outputs:**

- production code;
- component tests;
- browser tests;
- build and performance evidence.

## 10. Accessibility Specialist

**Owns:** WCAG 2.2 AA quality.

**Responsibilities:**

- review semantics and heading structure;
- test keyboard navigation;
- review focus management;
- review animation and reduced motion;
- validate contrast and status communication;
- review forms and errors.

**Outputs:**

- accessibility audit;
- remediation list;
- final accessibility approval.

## 11. SEO and Content Strategist

**Owns:** Search intent, content architecture and internal linking.

**Responsibilities:**

- research relevant search intent;
- define page topics without thin content;
- create metadata and structured-data requirements;
- plan future resources;
- validate indexability.

**Outputs:**

- SEO brief;
- keyword/intent map;
- metadata matrix;
- internal-linking plan.

## 12. Security, Privacy and Claims Reviewer

**Owns:** Security, privacy and assurance accuracy.

**Responsibilities:**

- verify hosting, storage and access claims;
- prevent unsupported certification statements;
- review form data handling;
- review cookies and analytics;
- approve assurance copy.

**Outputs:**

- assurance claim approval;
- privacy requirements;
- analytics constraints;
- launch blockers.

## 13. QA Lead

**Owns:** Cross-discipline release confidence.

**Responsibilities:**

- maintain the QA plan;
- verify acceptance criteria;
- test browsers and devices;
- validate links, forms and metadata;
- coordinate regression review;
- confirm documentation is current.

**Outputs:**

- test report;
- issue register;
- final launch recommendation.

## Recommended handoff sequence

1. **Brand Strategist** produces message architecture.
2. **Product Truth Reviewer** sets claim boundaries.
3. **UX Architect** produces journeys and page architecture.
4. **Senior Copywriter** writes page-level narratives.
5. **Creative Director** and **Web Designer** create distinct page directions.
6. **Graphic Designer** and **Motion Designer** develop assets and motion.
7. **Accessibility Specialist** reviews designs before implementation.
8. **Frontend Engineer** implements in slices.
9. **SEO**, **Claims**, **Privacy** and **Accessibility** reviewers inspect implementation.
10. **QA Lead** completes release review.

## Agent task contract

Every delegated agent task must include:

- named role;
- bounded objective;
- required source files;
- files it may change;
- files it must not change;
- required outputs;
- required checks;
- claim restrictions;
- completion criteria;
- handoff recipient.

## Recommended parallel work

Safe parallel streams:

- copywriter page drafts after message approval;
- graphic asset exploration after creative direction approval;
- SEO intent mapping;
- claims evidence collection;
- accessibility review of wireframes;
- frontend foundations while final long-form copy is being refined.

Avoid parallel changes to:

- global design tokens;
- navigation architecture;
- primary positioning;
- shared header/footer;
- domain and authentication configuration;
- the same page component.
